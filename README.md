# إعراب — نسخة تطوير عملية 0.7

> خريطة فهرس كتاب «النحو الواضح» المستخدم في توسيع الدروس: راجع `BOOK-ROADMAP.md`. العناوين هناك لا تُعد دروسًا مكتملة حتى يُكتب محتواها ويُختبر.

تطبيق ويب تقدمي عربي (PWA) بواجهة RTL. هذه النسخة تطوّر النموذج السابق إلى تطبيق محلي أكثر تكاملًا، مع دروس تأسيسية، أسئلة مفسّرة، حفظ تقدم، دفتر أخطاء، مراجعة مستحقة، اختبار تشخيصي، قاموس، إعدادات وتصدير/استيراد نسخة التقدم.

## محتويات النسخة
- `index.html`: هيكل التطبيق والتنقل الأساسي.
- `styles.css`: نظام التصميم المتجاوب، مع إعدادات حجم الخط والتباين وتقليل الحركة.
- `content.js`: طبقة المحتوى المستقلة (الدروس والأسئلة والمصطلحات وبيانات مراجعتها).
- `TEACHING-DESIGN.md` و`curriculum-map.md`: تصميم التعليم وخريطة الأبواب المقترحة.
- `tests/validate-lesson-template.cjs`: تحقق بنيوي من قالب الدرس التجريبي.
- `app.js`: منطق التنقل والتقييم والمراجعة والحفظ المحلي وإعدادات الواجهة.
- `manifest.webmanifest`: تعريف التطبيق المثبت ونطاقه وأيقوناته.
- `sw.js`: تخزين ملفات التطبيق الأساسية، بما فيها `content.js`، وتقديمها دون اتصال بعد اكتمال التحميل الأول.
- `icons/`: أيقونات PNG فعلية بمقاسي 192 و512.

## التشغيل المحلي
يتطلب PWA خدمة عبر `localhost` أو HTTPS؛ لا يكفي فتح `index.html` من مدير الملفات.

باستخدام Python:
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000` من الجهاز نفسه.

أو باستخدام Node.js:
```bash
npx serve .
```

## التثبيت على Android
1. انشر محتويات المجلد إلى استضافة HTTPS.
2. افتح الموقع في Chrome وانتظر اكتمال تحميله.
3. اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. افتح التطبيق المثبت مرة مع الاتصال، ثم أغلقه وافتحه من الأيقونة.
5. بعد اكتمال التخزين الأولي، اختبر فتح الدروس والتدريب في وضع الطيران.

## حفظ البيانات
التقدم محفوظ محليًا في `localStorage` ولا توجد حسابات أو مزامنة سحابية. استخدم «الإعدادات ← تصدير نسخة من تقدمي» لحفظ نسخة JSON. استيراد النسخة متاح من الشاشة نفسها. مسح بيانات المتصفح قد يؤدي إلى فقدان البيانات المحلية.

## حدود معروفة يجب عدم إخفائها
- المحتوى الحالي مسار تأسيسي عام من 12 درسًا و48 سؤالًا (43 اختيارًا من متعدد و5 أسئلة إجابة قصيرة تجريبية)، مع شرح سياقي وإعراب كامل للمثال الرئيسي في كل درس؛ يمثل بداية مسار عام، وليس بعدُ مسارًا شاملًا لكل أبواب النحو. جميع الأسئلة موسومة بأنها قيد المراجعة المتخصصة.
- المستخدم لا يشترط مطابقة منهج رسمي. مع ذلك، لا تزال مراجعة معلم متخصص للمحتوى غير منجزة؛ لذلك ينبغي اعتبار القواعد والأمثلة بحاجة إلى مراجعة بشرية قبل اعتمادها نهائيًا.
- لا يوجد حساب طالب أو مزامنة بين الأجهزة أو لوحة إدارة للمحتوى.
- اختبار تحديد المستوى عينة قصيرة إرشادية وليس تقييمًا معياريًا.
- اختبار Service Worker والأيقونات وفحص بناء JavaScript ثابت ممكن محليًا؛ لم يتسنّ التحقق من تثبيت فعلي على جهاز Android أو اختبار وضع الطيران بعد النشر عبر HTTPS من هذه البيئة؛ يجب تنفيذ هذا الاختبار قبل إعلان الجاهزية النهائية. يجب تنفيذ هذا الاختبار قبل إعلان الجاهزية النهائية.
- تم تضمين مبادئ عامة من أدبيات الاسترجاع النشط والمراجعة؛ لا يثبت ذلك وحده أن التطبيق حسن نتائج الطلاب، ويجب اختبار الأثر محليًا.

## سجل التحقق في هذه النسخة
- اجتاز `node --check app.js` و`node --check content.js`.
- اجتاز `python -m json.tool manifest.webmanifest`.
- اجتاز `node tests/validate-content.cjs`: 12 درسًا و48 سؤالًا و12 مصطلحًا، مع فحص المعرّفات وروابط الأسئلة وإجابة مرجعية واحدة لكل سؤال والبيانات الوصفية.
- اجتاز `node tests/smoke-init.cjs`: تهيئة التطبيق ورسم الصفحة الرئيسية وتهيئة التقدم محليًا ضمن DOM تجريبي بسيط.
- لم ينجح اختبار متصفح آلي كامل في بيئة البناء الحالية بسبب منع التنقل المحلي من المتصفح الآلي؛ لذلك لا يُعد اختبار التفاعلات الحقيقية منجزًا. لم يتم اختبار التثبيت/العمل دون اتصال على هاتف فعلي.
